QIANYANG OVERVIEW

千阳印象

黄土高原上的苹果明珠

千阳县地处陕西省宝鸡市北部，位于渭北旱塬丘陵沟壑区，是世界公认的苹果最佳优生区之一。这里海拔高、光照足、昼夜温差大，孕育出的苹果色泽鲜艳、肉质细脆、酸甜适口、香气浓郁。

千阳苹果先后获得"国家地理标志保护产品"、"中国果品区域公用品牌"等荣誉，远销海内外，成为当地农民增收致富的"金果子"。

HISTORICAL CONTEXT

历史文脉

古代 · 丝路果香

千阳自古为丝绸之路重要驿站，苹果的前身——"柰"（绵苹果）早在汉代便沿丝路传入，在千阳这片土地上生根发芽。

上世纪80年代 · 产业起步

千阳县开始规模化栽植苹果树，从山东、辽宁等地引进红富士、秦冠等优良品种，开启现代苹果产业发展之路。

2000年代 · 品牌崛起

千阳苹果获得国家地理标志保护产品认证，"千阳苹果"品牌逐步叫响全国，种植面积突破10万亩。

2010年代 · 转型升级

推广矮砧密植、水肥一体化、绿色防控等现代栽培技术，千阳苹果迈入标准化、集约化发展新阶段。

今日 · 走向世界

千阳苹果出口东南亚、欧洲等多个国家和地区，电商平台蓬勃发展，一颗小苹果串起了大产业、大市场、大未来。

APPLE VARIETIES

品种荟萃

千阳大地孕育的优质苹果品种

🍎

红富士

成熟期：10月中下旬

果形端正，色泽艳丽，肉质细脆，汁多味甜，耐储运，是千阳主栽品种。

🍏

嘎啦

成熟期：8月中下旬

果实中等大小，果皮薄，肉质脆嫩，酸甜爽口，是早熟苹果的代表。

🍏

澳洲青苹

成熟期：9月中下旬

果皮翠绿色，果肉紧实，酸度较高，适合加工与鲜食，风味独特。

🍎

维纳斯黄金

成熟期：10月下旬

黄色果皮，果肉脆甜多汁，香气浓郁，是近年来颇受欢迎的新品种。

🍎

瑞雪

成熟期：10月下旬

果面光洁，绿黄色带红晕，肉质细脆，风味浓郁，优质晚熟品种。

🍎

秦冠

成熟期：10月中旬

陕西本土培育品种，果大色红，适应性强，丰产稳产，风味醇厚。

GROWTH JOURNEY

生长之旅

一颗苹果的四季轮回

🌸 🌸 🌸 🌸 🌸

春日 · 繁花似锦

春风送暖，苹果树迎来花期。千阳万亩果园粉白相间的苹果花竞相绽放，蜂蝶飞舞，花香四溢。果农们忙着疏花、授粉，为丰收打下基础。

  • 关键农事：疏花、人工授粉、病虫害预防
  • 物候期：萌芽期 → 花期 → 坐果期
🍃 🍃 🍃 🍃 🟢

夏日 · 茁壮成长

烈日炎炎，苹果幼果在充足的光照下迅速膨大。果农们进行疏果、套袋、夏剪，确保每颗苹果都能获得充足的营养和阳光。

  • 关键农事：疏果定果、果实套袋、夏季修剪
  • 物候期：幼果膨大期 → 花芽分化期
🍎 🍎 🍎 🍎 🍎

秋日 · 硕果累累

金秋时节，千阳大地被染红。苹果褪去纸袋，在阳光下迅速着色，红得透亮、红得诱人。这是果农一年中最忙碌也最喜悦的收获季节。

  • 关键农事：摘袋、铺反光膜、采摘、分级
  • 物候期：果实着色期 → 成熟期 → 采收期
❄️ ❄️ ❄️

冬日 · 蓄势待发

白雪皑皑，苹果树进入休眠期。果农们利用冬闲时节进行整形修剪、清园消毒、施基肥，为来年的丰收积蓄力量。

  • 关键农事：冬季修剪、清园、施基肥、涂白
  • 物候期：落叶期 → 休眠期

果农故事

老张的矮砧果园

从传统乔化树到矮砧密植园，老张最直观的感受是：树更好管了，果更匀了，收成也更稳了。

乡村振兴

合作社里的“分工经”

有人管技术，有人跑销售，有人做分级包装。合作社把小农户接入大市场，让好苹果卖出好价钱。

科技育种

六次飞天的种子

航天搭载不是噱头，而是一次次筛选与试验。回到地面的种子，要继续经过田间观察才能走进果园。

怎么挑

  • 看色泽：着色均匀、果面光洁更成熟。
  • 摸硬度：轻按有弹性，过软可能存放较久。
  • 闻香气：成熟苹果有自然果香。

怎么存

  • 短期常温阴凉处，避免阳光直晒。
  • 长期冷藏 0-4℃，并用保鲜袋留少量透气。
  • 与香蕉、梨等释放乙烯的水果分开放。

怎么吃

  • 鲜食：红富士、秦冠适合直接吃。
  • 榨汁：酸甜平衡品种更适合搭配胡萝卜。
  • 烘焙：澳洲青苹酸味足，适合做派和果酱。
